The left and right generic hand models come from the Immersive Web Working Group’s
`@webxr-input-profiles/assets` package, version 1.0.20. Both models are distributed
under the included MIT license.

https://github.com/immersive-web/webxr-input-profiles/tree/main/packages/assets/profiles/generic-hand

These copies have one additional subdivision level. Edge midpoints follow the
surface normals and interpolate the original skinning weights for rounder
fingertips and knuckles.
